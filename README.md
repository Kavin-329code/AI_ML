# AI & Machine Learning Learning Roadmap

A practical repository tracking my progress, code, and hands-on projects as I learn Artificial Intelligence and Machine Learning fundamentals.

---

## 📌 Core Learning Topics

### 1. Python for Data Science
* **NumPy:** Vectorized operations, linear algebra basics, and array manipulation.
* **Pandas:** Data cleaning, filtering, handling missing values, and dataset aggregation.
* **Matplotlib & Seaborn:** Exploratory Data Analysis (EDA) and data visualization.

### 2. Machine Learning Fundamentals
* **Supervised Learning:**
  * **Regression:** Linear and Polynomial Regression for predicting continuous values.
  * **Classification:** Logistic Regression, Decision Trees, and Random Forests for categorization.
* **Unsupervised Learning:**
  * **Clustering:** $k$-Means and hierarchical clustering for finding natural groupings in data.
  * **Dimensionality Reduction:** Principal Component Analysis ($PCA$).

### 3. Model Evaluation & Optimization
* Data splitting ($Train/Test$) and $k$-Fold Cross-Validation.
* Evaluation metrics: Accuracy, Precision, Recall, $F_1$-Score, and Mean Squared Error ($MSE$).
* Hyperparameter tuning and preventing overfitting.
